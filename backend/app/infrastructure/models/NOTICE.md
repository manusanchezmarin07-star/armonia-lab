# Modelos incluidos

- `basic_pitch_nmp.onnx`: modelo de transcripción polifónica de [basic-pitch](https://github.com/spotify/basic-pitch)
  (Spotify, ICASSP 2022), licencia Apache 2.0. Copiado sin modificar de `basic_pitch/saved_models/icassp_2022/nmp.onnx`
  (versión 0.4.0). Se ejecuta con onnxruntime porque el paquete original requiere una versión de TensorFlow sin
  soporte para Python 3.12.
